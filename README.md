## 机械动力：更快的蓝图加农炮

---


另一个简单的机械动力附属，为蓝图炮带来配置修改！

1. 允许自定义蓝图炮的刻打印次数，最终效果为机械动力自己的刻延迟 乘以 此打印次数。
2. 允许自定义蓝图加农炮的禁止打印方块，当填入列表后，对应方块将会像基岩一样无法被蓝图炮破坏！因此默认配置会修复虚空锅炉。


---


# 配置文件说明

### 蓝图炮加速启用
- **EnableCannonSpeedUp**:
    - 这是一个布尔值，指示是否启用蓝图炮加速功能。设置为 `true` 则启用，设置为 `false` 则禁用。

### 每 tick 打印次数
- **SpeedupPerTick**:
    - 这个变量代表每 tick 蓝图炮进行的打印次数，与蓝图炮内的打印延时是相乘关系。
    - 计算公式为：打印速度 = 每 tick 蓝图炮打印的次数（本配置值） × 游戏刻（默认为 20） / [蓝图炮打印延时]（默认为 10）。
    - 范围：1 ~ 400

### 实验性游戏刻参数
- **lazyTick**:
    - 这是一个实验性参数，用于减少蓝图炮的游戏刻，即每多少刻执行一次蓝图炮代码。
    - 默认值为 1，您可以将其增加以减少卡顿，但这会使蓝图炮的响应变慢。
    - 建议的值为 5，与默认值相比慢了 4 倍，但可能不会明显感觉到变化。
    - 范围：1 ~ 200

### 不可破坏方块列表
- **blocks_unbreak**:
    - 这是一个列表，包含不能被蓝图炮摧毁的方块，以防止蓝图炮出现无尽锅炉 bug。
    - 示例：`["create:blaze_burner"]`

### 禁止消息启用
- **debug**:
    - 这是一个布尔值，指示当蓝图炮尝试破坏被禁止的方块时是否在控制台通知。设置为 `true` 则启用通知，设置为 `false` 则禁用。
